# フォルダとファイルの決まり

決まりは 2 つだけ。

- **年ごとに増えるもの**は「種類 → 年（1月〜12月）」の順でフォルダに分ける。
- **年に関係ないもの**は、年のフォルダを作らずに置く。

## 全体

```
github.io/
├─ index.html, about.html …   ページ本体（日本語）。URL が変わるので、場所や名前は変えない
├─ news.html                  記事の一覧（自動で作り直される）
├─ style.css, nav.css, sub.css, theme.css   見た目
├─ script.js（トップ）, sub.js（サブページ）   動き
├─ en/                        英語版のページ（ファイル名は日本語版と同じ）
│
├─ posts/                     ★年ごと：記事（スプレッドシートの articles から自動で作る）
├─ archive/                   ★年ごと：大会・イベントのページの保存版
├─ images/
│   ├─ site/                  年に関係ない写真（ロゴ・各ページの写真）。人が入れる
│   └─ posts/                 ★年ごと：記事の写真（自動で作る）
│
├─ overseas/                  海外レース挑戦記（昔の参戦記。手で作ったページ）
├─ data/                      年間スケジュールのデータ（自動で作る）
├─ scripts/                   自動で動くプログラム
├─ docs/                      手順書（このファイルもここ）
└─ .github/workflows/         GitHub のボタン・自動処理
```

## ★ 年ごとのフォルダ

### 記事：`posts/年/`

```
posts/2026/2026-08-07_1_8月の練習会レポート.html
            ^日付      ^記事id ^タイトル
```

- 年は記事の「日付」の年。日付やタイトルを変えると、ファイル名も自動で変わる（記事id で同じ記事と見分ける）。
- 手で作ったり消したりしない。スプレッドシートの「載せる」で出し入れする。

### 記事の写真：`images/posts/年/記事と同じ名前/`

```
images/posts/2026/2026-08-07_1_8月の練習会レポート/01.webp
                                                   02.webp
```

- Google Doc に貼った写真を、自動で縮めてここに置く。番号は Doc の中の順番。
- 記事を消すと、写真のフォルダも一緒に消える。

### 大会・イベントの保存版：`archive/年/`

```
archive/2027/hukilau.html
archive/2027/oshima.html
archive/2027/en/hukilau.html
```

- 作り方は `docs/RACE_ARCHIVE.md`。

## 年に関係ないもの

### サイトの写真：`images/site/`

| フォルダ | 中身 |
|---|---|
| `header/` | ヘッダーのロゴ |
| `hero/` | トップと各ページの大きな写真（PC 用は `pc_`、スマホ用は `mobile_` で始める） |
| `about/` | クラブについて・トップの ABOUT |
| `contact/` | お問い合わせ・トップの JOIN US |
| `events/` | 大会・イベントのページ（Ho'aikane のロゴ・賞、大島クロッシングなど） |
| `ogp.png` | SNS で共有したときに出る画像 |

- 写真を足すときは、使うページに合うフォルダに入れる。迷ったら、ページの名前のフォルダを新しく作る（例：`kids/`）。
- ファイル名は英数字と `_` だけにする（例：`oshima_crossing.jpg`）。

## 自動で作られるもの（手で直さない）

| 場所 | 作るもの | 元になるもの |
|---|---|---|
| `posts/`、`images/posts/` | 記事と写真 | articles シート＋Google Doc |
| `news.html` などの記事カード | カードの一覧 | articles シート |
| `data/schedule.js` | 年間スケジュール | schedule シート |
| 各ページの `data-cms` の付いた文章 | ページの文章 | 基本情報・FAQ・content シート |
| `archive/` の保存版の固定と、一覧 | 保存版 | 「大会・イベントのページを保存」ボタン |
