# サブページ実装計画

トップページ (`index.html`) の見た目は変えずに、サブページを追加していくための計画と決まりごと。
作業を再開するときは、まずこのファイルを読むこと。

## 決まりごと

- `style.css` と `script.js` はトップページ用。**変更しない。**
- サブページは `style.css` に加えて次の共通ファイルを読み込む。
  - `nav.css` … スマホ用メニューの開閉（トップページと共通）
  - `sub.css` … サブページ共通の部品（ページ上部の写真、見出し、表、カード、FAQ など）
  - `sub.js` … メニュー開閉、ヘッダーの色切り替え、ページ内スクロール
- ヘッダーとフッターはトップページと同じ HTML を使う。メニューは下の6ページ。
- 新しい見た目の部品が必要になったら、ページごとに書かず `sub.css` に足して使い回す。
- 確定していない内容には `<span class="kari">【仮】</span>` を付ける。確定したら外す。
- 1作業 = 1プルリクエスト。マージ後に「Generate Posts」を実行し、成功とページ表示を確認してから次へ進む。

## COCC KIDS の Instagram ギャラリー（`kids.html`）

- 見た目は `sub.css` の `.insta-grid`。PC・タブレットは「大きな1枚＋小さな4枚」、スマホは横に流せるカルーセル。
- 方針（2026-10-03）: 実際の投稿の表示は、外部サービスのウィジェットではなく Instagram の API を使う形にしたい。実装は後日。それまでは今の仮の写真のままにする。
- 位置は「KIDSプログラムとは」の下、「活動内容」の上。
- 参考: 外部サービスのウィジェット（埋め込みコード）を使う場合は次のとおり。コードをもらったら、`<ul class="insta-grid">…</ul>` を次のように置き換える。

```html

  （サービスから発行された埋め込みコード）

```

- 置き換えたら、「写真は準備中です…【仮】」の1行（`.insta-note`）も削除する。
- ページを作り直す生成スクリプトはリポジトリに入れていない。以降の変更は HTML を直接編集する。

## 英語版（`en/`）

- 日本語ページと同じファイル名で、`en/` フォルダに英語版を置いている（9ページ）。
- ヘッダーの「JP / EN」で、同じページの別の言語に切り替わる。
- 日本語ページの内容を変えたら、`en/` の同じページも直す（自動では同期しない）。
- 共通ファイル（`style.css` `nav.css` `sub.css` `sub.js` `script.js` と画像）は日本語と共用。サブページは `../` で参照している。
- `en/index.html` だけは `<base href="../">` を使い、パスをサイトの最上位から解決している（`script.js` のスライド画像のパスを変えずに使うため）。このページ内のリンクは `en/…` と書く。
- 英語トップの NEWS は、日本語サイトへの案内のみ。記事（`posts/`）は日本語で、ワークフローが更新するのは日本語の `index.html` だけ。
- 【仮】は英語版では `[TBC]` と表記。

## メニュー

- 「会員案内」「大会・イベント」「お問い合わせ」には、押すと開く小さな項目がある。項目名を押すとそのページへ、右の「＋」を押すと中が開く。HTML は `<li class="has-sub">` と `<ul class="sub-menu">`、見た目は `nav.css`、開閉は `script.js`（トップ）と `sub.js`（そのほか）。
- 小さな項目を足すときは、全ページのメニューと `scripts/post_template.js` に同じ行を足す。

- PC でもスマホでも、メニューボタンを押して開く形（`nav.css`）。`style.css` は変えていない。

## 年間スケジュール（`events.html` の `#event-schedule`）

- 年間スケジュールは「大会・イベント」だけに置く。「会員案内」からは目次のリンクで飛ぶ（重複させない）。
- **予定はスプレッドシートの「schedule」シートで直す。** 公開（Generate Posts）のたびに `scripts/update_schedule.js` がシートを読み、`data/schedule.js` を作り直す。シートが無い・読めない・使える行が無いときは、今の `data/schedule.js` をそのまま使う。シートの見本は `docs/schedule_sheet_sample.csv`（1 行目が列名、2 行目が説明、3 行目から予定）。日付が「※」の行はその年の注記。「仮の年?」が「はい」の行がある年には、仮の注記が出る。
- 中身は `data/schedule.js` の 1 ファイルにまとめている。日本語版・英語版の両方がこのファイルを読む。表示するプログラムは `sub.js` の「年間スケジュール」の部分、見た目は `sub.css`。
- **年を足すとき**: シートに、新しい年の行を足すだけ。HTML は触らない。過去の年は消さずに残す。年の切り替えボタンは自動で増える。
- 最初に開く年は「今年のデータがあれば今年、なければいちばん新しい年」。`events.html?year=2025` のように URL で年を指定することもできる（過去の年へのリンクに使える）。
- 各項目の書き方は `data/schedule.js` の先頭のコメントに書いてある。
- スマホでは 1 件を 1 行に収め、押すと補足と主催／開催地が開く。PC では最初から右側に出る。
- `provisional: true` の年には「仮の内容です」という注記が出る。2025 年は仮（2026 年の予定をもとに月だけを入れたもの）。
- 「結果」と「ギャラリー」は削除した。代わりに「イベントレポート」の欄があり、今はトップページの NEWS へ案内している。

- 全ページの `<head>` に OGP のタグを入れている。画像は `images/site/ogp.png`（1200×630、白地にヘッダーのロゴ）。

## 記事ページ（`posts/年/*.html`）

- ひな形は `scripts/post_template.js`。サイト共通のヘッダー・フッターと `style.css` `nav.css` `sub.css` を読み込む。見た目は `sub.css` の「記事ページ」の部分（`.post-…`）。
- 記事の見た目を変えたいときは `sub.css` を直せば、既存の記事にもすぐ効く。
- ヘッダーやメニューなど HTML の構造を変えたときは、ひな形を直す。既存の記事は、「Generate Posts」を「変わっていない記事も全部作り直す」にチェックを入れて手で動かすと作り直される。
- 「画像url(複数可)」に URL があれば、本文の下に写真として並ぶ。1 枚目は共有時の画像にもなる。
- notes 列（カテゴリ）は、空または「無し」のときは表示しない。

## 茅ヶ崎らしさのテーマ（`theme.css`）

- 色・書体・あしらいは `theme.css` にまとめ、全ページでほかの CSS のあとに読み込んでいる。`style.css` `sub.css` `nav.css` は変えていない。
- 色は `theme.css` の先頭の `:root` で決めている（砂浜の白、海の紺、朝の海の青緑、朝日の色）。ここを変えれば全体が変わる。
- 書体は Google Fonts の Cormorant Garamond（英字の見出し）、Shippori Mincho（日本語の見出し）、Zen Kaku Gothic New（本文）。
- 区切り線とフッターの線画は、水平線の上に烏帽子岩が立つ形（CSS に埋め込んだ SVG）。
- 新しいページを作るときは、`<link rel="stylesheet" href="theme.css">` を CSS の最後に足す。
- テーマだけを外したいときは、各ページのこの 1 行を消す（または `theme.css` を空にする）と、以前の白・黒・Bebas Neue の見た目に戻る。

## スプレッドシートと HTML の関係（文章を直すときの注意）

- `data-cms` の付いた文章は、公開のたびにスプレッドシート（`基本情報`・`content`）の内容で上書きされる。
- そのため、HTML の文章を直接書き換えたときは、スプレッドシートの同じキーの行も直す。直さないと、次の公開で元に戻る。
- `FAQ:START〜END`（`faq.html`）と `OSHIMA:START〜END`（`oshima.html`）の間は、それぞれ `FAQ`・`oshima` シートから丸ごと作り直される。

## Ho'aikane のページの雰囲気

- `hoaikane.html` は `<body class="theme-hoaikane">`。色（ロゴのピンク、濃いローズ、薄いピンクの地）と書体（英字の見出しは Fraunces）は、`sub.css` の末尾「Ho'aikane のページだけの雰囲気」で決めている。ほかのページには影響しない。
- ロゴは `images/site/events/hoaikane_logo.png`（白い図柄だけを切り抜いた、背景が透明の画像）。
- 大会・イベントのカードの画像は `images/site/events/hoaikane_card.jpg`（メダルの写真・ペンダントの写真・ロゴを 1 枚に組み合わせたもの）。写真を替えるときは作り直す。

## Hukilau Challenge のページの雰囲気

- `hukilau.html` は `<body class="theme-hukilau">`。色（墨に近い紺と朱）や見出しの朱の線、墨色の帯は、`sub.css` の末尾「Hukilau Challenge のページだけの雰囲気」で決めている。ほかのページには影響しない。
- 写真のすぐ下の帯（`.next-race`）に、次回の開催日を出している。日付はスプレッドシートの `content`（キー `hukilau.next.date`）から直せる。
- タイムスケジュールは、1 日目・2 日目を押すと開く形。
