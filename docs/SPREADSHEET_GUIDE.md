# スプレッドシートでサイトを更新する

スプレッドシート「COCC Articles」が、サイトの管理画面です。
シートを直してから「サイトに反映する」を行うと、3〜5分ほどでサイトに出ます。

## シートの役割

| シート | 直せるもの |
|---|---|
| `基本情報` | 会費、活動時間、KIDS の料金と活動日、体験の時間例と持ち物、住所、代表の言葉 |
| `FAQ` | よくある質問（1 行に 1 問。行を足せば質問が増える） |
| `schedule` | 年間スケジュール（1 行に 1 つの予定） |
| `articles` | NEWS の記事（1 行に 1 記事。本文は Google ドキュメント） |
| `公開` | 「サイトに反映する」のチェックボックス（下の設定をしたあとに使える） |
| `content`（非表示） | 上のシートに無い、そのほかの文章すべて。ふだんは触らない |

## `基本情報` シートの書き方

- 「内容（日本語）」と「英語」の列だけを書き換える。「項目」の列は変えない。
- 行を足したり消したりしない（項目を増やしたいときは依頼する）。
- 【仮】（英語は [TBC]）と書くと、赤い「仮」の印になる。確定したら消す。
- 改行は、そのまま改行になる。
- リンクは `[表示する文字](membership.html)` や `[表示する文字](https://…)` と書く。
- 欄を空にしても、サイトの文章は消えない（今の文章のまま）。

## `FAQ` シートの書き方

- 1 行に 1 問。「分類」「質問」「答え」を書く。3 つのどれかが空の行は出ない。
- 行を足すと質問が増え、行を消すと質問が消える。並びはシートの上から順。
- 同じ「分類」の行が、1 つのまとまりになる。新しい分類の名前を書けば、分類が増える。
- 英語の 3 列は、空なら日本語がそのまま英語版に出る。
- 答えの中でも、【仮】とリンクの書き方が使える。

## `content` シート（非表示）

- サイトの文章すべて（約 430 行）が入っている。`基本情報` に無い文章を直したいときに使う。
- 表示するには、シートの一覧（左下の ≡）から選ぶ。
- 同じ文章が `基本情報` にもあるときは、`基本情報` が優先される。

## `schedule` シートの書き方

- 1 行目が列名、2 行目が説明、3 行目から予定。並びはシートの上から順。
- 年を足すときは、新しい年の行を足す。
- 日付の列に「※」と書いた行は、その年の注記になる。

## `articles` シートの書き方

- 1 行目が列名、2 行目から記事。
- 「公開する?」を「はい」にすると NEWS に出る。「生成済?」は自動で「はい」になる。
- 記事を直したときは「修正する？」を「はい」にする。

## 「サイトに反映する」をスプレッドシートから行う設定（最初に 1 回）

パソコンで行う。

1. GitHub で鍵を作る：右上のアイコン → Settings → Developer settings →
   Personal access tokens → Fine-grained tokens → Generate new token。
   - Resource owner: `Chigasaki-Outrigger-Canoe-Club`
   - Repository access: Only select repositories → `github.io`
   - Permissions → Repository permissions → **Actions: Read and write**
   - 期限を決めて作り、表示された鍵をコピーする（この画面でしか見られない）。
2. スプレッドシートで「拡張機能」→「Apps Script」を開く。
3. 出てきた画面の中身を消して、`docs/apps_script_publish.gs` の中身を貼り、保存する。
4. 左の歯車（プロジェクトの設定）→「スクリプト プロパティ」→ プロパティを追加。
   名前 `GITHUB_TOKEN`、値に 1 でコピーした鍵を入れて保存する。
5. 上の関数の選択で `setupMobileTrigger` を選び、「実行」を押す。権限の確認が出たら許可する。
6. スプレッドシートを開き直す。

使い方

- パソコン：メニューの「サイト」→「サイトに反映する」。
- スマホ：`公開` シートのチェックボックスにチェックを入れる。結果が下のセルに出る。

注意

- 鍵には期限がある。切れたら 1 と 4 をやり直す。
- 鍵はスクリプト プロパティにだけ入れる。シートのセルやチャットには書かない。
- GitHub の画面から「Generate Posts」を手で動かす方法も、今までどおり使える。
